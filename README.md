# Simple Prompt Caching Simulation

This Python script demonstrates the core concept of prompt caching. It simulates a time-consuming Large Language Model (LLM) response and uses a simple in-memory cache to store and retrieve previously processed prompts. The example highlights how repeated queries for the same prompt result in significantly faster responses by serving them directly from the cache, thereby improving performance and reducing computational load.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
